# 新手指南书配置手册（guide_book.yml）

> **状态：现行** ｜ **最后更新**：2026-09-16

给服主看的 3 分钟上手手册：改完执行 `/orzmc config reload`，玩家 `/guide` 立即看到新内容（无需重启）。
面向开发者的解析/渲染实现见 `docs/dev/` 与 `src/main/java/.../infra/guidebook/`。

---

## 1. 三条规则（先读这个）

1. **一行 = 一句话**（段后自动空一行，长段落直接写，客户端会自动折行）。
2. **一页 = 一个 `-` 列表**；想翻页就再起一个 `-` 列表（不需要 `page_break` 之类的开关）。
3. **要样式/链接时用记号**：`**粗体**`、`<u>下划线</u>`、`[文字](https://地址 '悬停提示')`。

<!-- guide-book-example:start -->
```yaml
# guide_book.yml —— 最小可用示例（可直接整段替换你的文件）
enable: true
title: 新手指南
author: 腐竹
pages:
  - # ===== 第 1 页 =====
    - 欢迎新朋友来到我的世界！
    - 服务器中一些热爱创造的小伙伴在这里花费了大量心力建造出了各种漂亮的建筑，希望刚加入的朋友不要随意对其进行破坏。
    - ""
    - "**相关链接**"
    - "[服务器主页](https://orzmc.jokerhub.cn '点击前往主页')"
    - "[玩家手册](https://orzmc.jokerhub.cn/user/ '点击查看玩家手册')"
  - # ===== 第 2 页 =====
    - "[MC插件使用百科书](https://mineplugin.org/ '点击跳转插件百科')"
```
<!-- guide-book-example:end -->

## 2. 速查表

| 你想写的内容 | 这样写 |
|---|---|
| 普通文字 | `- 欢迎来到本服` |
| 空一行（拉开段落间距） | `- ""` |
| 粗体 | `- "**相关链接**"` |
| 下划线 | `- "<u>请先读这里</u>"` |
| 加粗 + 下划线 | `- "**<u>重要</u>**"` |
| 行内局部加粗 | `- "**重点**：后面的字是普通字"` |
| 可点击链接 | `- "[服务器主页](https://orzmc.jokerhub.cn)"` |
| 链接 + 悬停提示 | `- "[服务器主页](https://orzmc.jokerhub.cn '点击前往主页')"` |
| 翻到下一页 | 再起一个 `-` 列表（见示例第 2 页） |
| 表面字面量 `**` 或 `[` | 加反斜杠转义：`\*\*`、`\[` |

**要点**

- 含记号的行建议用双引号包住整行（`- "**标题**"`），避免 YAML 误判；纯中文文字不加引号也可以。
- 链接必须**整行**只有链接；`[文字](地址` 括号不完整、`[文字]()` 空地址都会被当作普通文字并在日志告警。
- 记号必须成对：只写 `<u>` 忘了 `</u>`，该行会按普通文字渲染（内容不丢）并在日志告警。
- 颜色不在简写记号里，用下面 §3 的全写法。

## 3. 全写法（需要颜色 / 精细控制时）

简写与全写法可以**混用**，一行想怎么写就怎么写：

```yaml
pages:
  - 
    - text: 加粗标题            # 文字行
      bold: true
      underlined: false
      color: "AQUA"            # 命名色（red / AQUA / gold …）或 #RRGGBB
      newline_count: 2         # 这段后面空几行（默认 1；0 = 与下一行紧贴）
    - link: 服务器主页          # 链接行
      url: https://orzmc.jokerhub.cn
      hover: 点击前往主页
```

| 键 | 含义 | 默认 |
|---|---|---|
| `text` / `link` | 行类型（二选一） | — |
| `bold` / `underlined` | 整行加粗 / 下划线 | `false` |
| `color` | 命名色或 `#RRGGBB`；非法值忽略并在日志告警 | 无（链接默认蓝色） |
| `newline_count` | 本行之后空几行 | `1` |
| `url` / `hover` | 链接地址 / 悬停提示（`link` 行） | 无 |

> 顶部 `enable: false` 可临时关闭指南书（`/guide` 会提示「服主未配置新手指南」，首次进服也不再发放）。

## 4. 上限与降级（不会导致 `/guide` 报错）

| 情况 | 行为 |
|---|---|
| 单页超过 1024 字符（原版上限） | 省略该页末尾超出的行，日志告警并提示拆页 |
| 超过 100 页（原版上限） | 省略末尾页，日志告警 |
| 某页没有任何内容 | 跳过该页（不出现白页） |
| 颜色 / 布尔值 / 数字类型写错 | 该字段按默认值处理，日志告警，其余内容照常渲染 |
| 记号不成对、链接写法不完整 | 该行按普通文字渲染，日志告警（**内容不会丢**） |

日志在服务器控制台与 `logs/latest.log` 中，前缀为 `guide_book.yml:`。

## 5. 生效方式与旧格式迁移

- **改完即生效**：编辑 `plugins/OrzMC/guide_book.yml` → `/orzmc config reload`（或 `/orzmc config reload guide_book`）→ 玩家 `/guide` 查看效果。
- **旧格式自动迁移**：老版本的 `content:` 写法仍然可读；插件启动时会把文件**自动迁移**为本手册的 `pages:` 格式，
  原文件备份为 `guide_book.yml.bak`。迁移只在首次发生（迁移后不再改写），且迁移前会做一致性回读校验，
  校验失败则保留原文件不动（只记录日志）。迁移生成的文件**自带本手册的速查注释**，且启动流程不会再回写抹掉注释。
- **格式问题会主动上报**：启动时的配置健康检查会列出 `guide_book.yml` 的问题（含页号/行号），
  形如 `guide_book.yml: 第 1 页第 5 行: 链接缺少地址…`；同一问题在渲染时也会写日志。
- **迁移前的旧写法对照**（了解即可，不必手写）：

| 旧格式 | 等价新格式 |
|---|---|
| `- text: {content: 文字, newline_count: 2}` | `- text: 文字` + `newline_count: 2` |
| `- text: {content: 标题, style: {bold: true}}` | `- "**标题**"` |
| `- link: {content: 主页, url: https://…, hover_text: 点我}` | `- "[主页](https://… '点我')"` |
| `- link: {…, page_break: true}` | 结束当前页，下一页从下一条开始（在 `pages:` 下新建一个 `-` 列表） |

## 6. 排查清单

1. `/guide` 提示「服主未配置新手指南」→ 检查 `enable` 是否为 `false`、`pages:` 是否为空或缩进错误。
2. 内容是旧样子 → 执行了 `/orzmc config reload` 吗？确认文件位置是 `plugins/OrzMC/guide_book.yml`（不是 jar 内资源）。
3. 某行没按预期加粗 → 记号是否成对、是否整行使用了引号；看控制台 `guide_book.yml:` 告警。
4. 颜色不生效 → 用命名色（`red`）或 `#RRGGBB`（如 `#5555FF`）；`AQUA#` 之类非法值是告警 + 忽略。
5. YAML 缩进报错 → `pages:` 下每页的 `-` 对齐，页内每行的 `-` 再缩进一级（照抄 §1 示例即可）。
