# 录制清单（按片分节）

> **状态：现行** ｜ **最后更新**：2026-10-02
> 用法：录屏前对照本节「录什么」，录屏后逐条自检。**原始录屏不入库**（放仓库外或用 `VIDEO_WORKDIR` 指到仓库外）。
> 素材命名与分镜镜号一一对应 ⇒ **支持单镜重录替换**。

## 通用要求

| 项 | 要求 |
|:--|:--|
| 分辨率 / 帧率 | 1920×1080 @ 60fps（横屏主片）；9:16 切片另录或后期裁切（安全框见下） |
| 光标 | 放大到 150%、加高亮光晕（录屏软件设定） |
| 录制范围 | 只录必要区域（群聊窗口 / 游戏窗口 / 终端），不出现桌面、通知、其它窗口 |
| 音频 | 先录无声画面（口播/音乐后期配）；如需现场口播，另存干净音轨 |
| 文件命名 | `epNN_MM_topic.mp4`（如 `ep00_02_group_cmds.mp4`），与源文件 `shots[].asset` 完全一致 |
| 单镜时长 | 允许 ≥ 分镜时长，**不要短于**（剪辑时按分镜裁剪） |
| 9:16 安全框 | 上下各留 12% 安全区（避开平台 UI），字幕避开底部 15%；关键操作居中 |
| 录屏目录 | `$VIDEO_WORKDIR/<epNN>/raw/`（默认 `videos/.build/<epNN>/raw/`，已 gitignore）；建议仓库外 |

### ⚠️ 敏感信息遮蔽清单（录制前先清场，录后逐帧复查）

| 类别 | 处理 |
|:--|:--|
| 服务器 IP / 域名 / 端口 | 用合成值（如 `mc.example.com:25565` → 演示环境用 `play.local:25565`）；必要时马赛克 |
| QQ 群号 / 会话 ID / openid | 遮蔽或改备注为「管理群」「玩家群」；`0F1E…E1F0` 形态的合成值可用 |
| Bot Token / API Key / RCON 密码 | **绝不入画**：配置文件里对应行先替换为 `***` 或折叠；终端不回显凭据 |
| 玩家真实昵称 | 用测试账号（如 `Test01`…）或打码；避免真实玩家隐私 |
| 后台面板地址 / 账号 | 不录面板画面；必要时只录控制台命令回显 |

> 提交与分享前再跑一次：`videos/tools/verify.sh`（内含源级敏感信息模式检查）。

## 录完后的收尾

1. 素材按命名放入 `$VIDEO_WORKDIR/<epNN>/raw/`（仓库外）；
2. 复核敏感信息清单（逐帧扫一遍群名、ID、IP、Token）；
3. 合成时对齐 `.build/<epNN>/<epNN>.zh-CN.srt` 与分镜时长（口播样音 `preview/*.mp3` 可作配音参考）；
4. 发布后回填 `status.md`（成片链接 + 适用版本），命名按 `V1-宣传-v1.0.28`；
5. 若后续功能变更命中本片：改源 → `make.sh <id> --all` 重生成 → 单镜重录 → 发新版。
