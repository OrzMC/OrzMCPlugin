## 一、系列定位

- **EP0 宣传短片**：聚焦核心功能、**小而美**（≤90s），目标是「吸引用户」——只讲三个最强卖点，不铺功能。
- **EP1–EP25 功能分集**：**一集一个功能点**，用简洁易懂的方式讲清楚、讲明白；单集 **硬上限 3 分钟**（目标 120–150s）。
- 一条叙事主线：**群聊管服（差异点）→ 权限成长（社区）→ 安全与数据兜底（信任）→ 配置与运维（可维护）→ 快速上手（落地）**。

## 三、拆集规则（3 分钟装不下就拆，不压缩语速）

| 触发 | 示例 | 拆法 |
|:--|:--|:--|
| 单集信息点 > 3 | `§5 安全`（8 个子节） | 拆 4 集：EP11 GeoIP / EP12 访问规则 / EP13 守卫+反垃圾 / EP14 限流+加固 |
| 单集功能分支多 | `§15 权限` | 拆 4 集：EP7 自动晋升 / EP8 审核闭环 / EP9 手动升降级 / EP10 prison |
| 需要多环境录制 | `§2 Bot` | 拆 3 集：EP1 命令体系 / EP2 通道选型 / EP5 通知（+EP6 模板） |
| 操作链条长（>4 步） | 备份与优化 | 拆 2 集：EP20 备份 / EP21 优化（各自独立痛点） |
| 出现「顺带讲一下」 | 任意 | 把「顺带」内容变成下一集的钩子（片尾预告），本集只讲一个点 |

**每集固定结构**（模板见 `_template/episode.yml`）：片头 3–5s → 痛点 15–20s → 原理/体系 20–30s → 实操演示 40–60% → 玩家/管理侧反馈 15–20s → 要点卡 + 下集预告 10–15s。

## 五、品牌与产线

- **品牌 token**：[`brand/brand.yml`](brand/brand.yml)（主色 `#4FC3F7`/`#0288D1`、强调 `#FFD54F`、圆角 8px、水印右下角 15%；字体 PingFang → Hiragino Sans GB → STHeiti 降级链）。
- **产线**：改 `epNN.yml` → `make.sh epNN --all`（人读稿 / SRT / 卡片 / 口播样音）→ 录屏（清单）→ 配音 → 合成 → 发布 → 回填看板。
- **仓库零产物**：只跟踪源与工具；产物在 `.build/`（忽略），原始录屏建议放仓库外。
- **迭代更新**：功能变更 → `affected-episodes.py` 判定 L1/L2/L3 → 按 [`UPDATE.md`](UPDATE.md) 处置 → 更新看板。
